📸 About the Project

This project is a classic two-player Tic-Tac-Toe game developed as part of my journey learning React.

The goal was to practice React fundamentals, particularly components, state management, and event handling.

✨ Features

Two-player gameplay.

Interactive game board.

Automatic winner detection.

Draw detection.

Game reset functionality.

Responsive user interface.

🛠️ Built With

React – UI library.

Vite – Frontend build tool.

JavaScript – Application logic.

CSS – Styling.
